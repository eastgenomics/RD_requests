# Creating a all_panels_and_test_codes.json file
A git repo folder to make a new json file for the WGS workbook workflow.

## Context
This is a json file that maps every panel in signed off GMS panel app with the panel ID as the key, and the panel name and test code as the values e.g.

## Running the script
```
$ python create_wgs_json.py "261008_all_panels_and_test_codes.json"
Wrote 296 panels to 261008_all_panels_and_test_codes.json
```
